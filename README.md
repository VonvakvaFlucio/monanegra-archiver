i've created this bash script that is an automatic archiver based on ytdlp, some parts were ai generated, but i did some for learning too

**usage:** ./monanegra.sh \"<search term>\" <DATE_YYYYMMDD> <quantity> \
**example:** ./monanegra.sh \"lollapalooza 2018\" 20181231 5 

if you don't know what yt-dlp is, check [this](https://github.com/yt-dlp/yt-dlp)
